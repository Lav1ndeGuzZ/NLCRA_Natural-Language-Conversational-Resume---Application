授权配置

          
页面顺序：先获取授权 Token，再使用 CLI 提供的能力

        


        

          

            

              
将 Token 配置到猎聘 CLI（环境变量或配置文件）后，即可调用下方能力。

              

                登录并点击「立即生成凭证」后显示
                
              

              

                
                登录猎聘获取凭证
              

              
凭证有效期为 90 天；重新生成后旧凭证会立即失效，请同步更新本地 CLI 中的 Token。

            

          

        

      

    


    
    

      

        

          在终端执行以下命令，查看全部子命令与参数：
          

            liepin-cli --help
            
          

        

        

          
CLI 提供的能力

          
猎聘简历与职位接口 CLI，以下为常用一级命令摘要。

        


        

          

            
setup

            
liepin-cli setup

            
首次配置或刷新登录状态。

            
    
              
  • 适合首次安装 CLI 或 Token 失效后重新配置
    • 
            

          


          

            
auth

            
liepin-cli auth

            
管理认证。

            
    
              
  • 查看、更新与当前授权相关的认证信息
    • 
            

          


          

            
resume

            
liepin-cli resume

            
查询或更新简历。

            
    
              
  • 读取简历内容、分模块完善与保存
    • 
            

          


          

            
job

            
liepin-cli job

            
搜索职位、投递职位。

            
    
              
  • 按条件检索职位并发起投递
    •
